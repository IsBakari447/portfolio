# Issa Bakari Portfolio

This repository contains the personal portfolio website of Issa Bakari. It presents skills, experience, GitHub projects, CV download and contact information in a responsive static website.

Live website:

```text
https://isbakari447.github.io/portfolio/
```

## Features

- Responsive portfolio homepage
- About, skills, projects, experience, CV and contact sections
- Multilingual interface with in-page translations
- Project cards for EnterpriseERP, EnterpriseERP.Mobile, EnterpriseERP Cloud, Poussin-D-Ore, LandingCraft and other GitHub projects
- Downloadable CV
- Profile image and personal branding
- Static deployment through GitHub Pages

## Tech Stack

- HTML
- CSS
- JavaScript
- GitHub Pages

## Project Structure

```text
index.html          Main portfolio page
image.jpg           Profile image
cv-issa-bakari.pdf  Downloadable CV
```

## Local Preview

Because this is a static website, you can open `index.html` directly in a browser.

Optional local server:

```bash
python -m http.server 8080
```

Then open:

```text
http://localhost:8080
```

## Deployment

The project is deployed with GitHub Pages.

Recommended GitHub Pages settings:

```text
Source: Deploy from a branch
Branch: main
Folder: /root
```

After pushing to `main`, GitHub Pages will update the live website automatically.

## Maintenance

- Keep project links up to date.
- Verify all language labels after editing content.
- Keep the CV file current.
- Check mobile layout after major content changes.
